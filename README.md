# Rika Ipsum 🦄🌈

Zagyva szöveggenerátor 12 féle ipsummal: Rika, Lorem, Marvel, DC, Meow, Palindrom, Csillám, Mazsola, Akir Muspi, Kalóz, Street Food és Meeting Ipsum.

**Élő oldal:** https://mazsola739.github.io/rika-ipsum/

- bekezdés, mondat, szó vagy maximális karakterszám szerint generál
- a nyitómondat, az emojik és a `<p>` tagek ki-be kapcsolhatók
- egy generátor közvetlenül is linkelhető, pl. `#marvel` vagy `#palindrom`
- egyetlen `index.html`, nincs build és nincs függőség

Készült 2021-ben, felújítva 2026-ban.
